📌 About
A modern, full-stack E-Commerce platform for "Roast & Bean" specialty coffee, designed to deliver a seamless shopping experience. The application features an interactive product showcase with real-time search and filtering, a dynamic cart management system, and a robust checkout flow connected to a RESTful backend API.

📄 Pages / Features

Catalog / Showcase — main interface featuring an interactive product grid, real-time keyword search, roast level filtering (Light, Medium, Dark), and price sorting

Product Details Modal — detailed modal view displaying coffee bean origins, flavor profiles, roast descriptions, and single-click cart additions

Shopping Cart & Checkout — reactive slide-over/page cart supporting instant quantity adjustments, price calculation, and customer address intake

Order Confirmation — post-checkout screen generating unique order IDs and summary confirmation details

✨ Key Features

☕ Smart Search & Filtering — instant client-side filtering by name, roast level, and ascending/descending price sorting

🛒 Dynamic Shopping Cart — reactive global state management for effortless item additions, updates, and cart clearing

📱 Fully Responsive — warm, modern specialty coffee design built to adapt seamlessly across mobile, tablet, and desktop devices

⚡ Fast & Reactive — high-performance REST API integration between Vite/React frontend and Express backend

🛠️ Tech Stack

Client (Frontend) • React & TypeScript — component-based architecture with strict typing • Vite — lightning-fast build tool and dev server • Tailwind CSS — utility-first styling for modern UI components • Zustand — lightweight state management for global cart persistence • React Router — seamless client-side single-page routing

Server (Backend) • Node.js & Express — RESTful API architecture written in TypeScript • CORS & Middleware — secure cross-origin handling for cloud deployment • REST Endpoints — structured routes for catalog retrieval (/api/products) and order placement (/api/orders)
